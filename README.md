# cafe-landing

가상의 카페 "모닝브루"를 소개하는 간단한 랜딩 페이지입니다. 별도의 빌드나 설치 없이 순수 HTML/CSS로 만들어졌습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (상단 메뉴, 히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 (카페 느낌의 브라운 톤, 모바일 대응 반응형) |
| `README.md` | 이 폴더에 대한 설명 |

## 사용 방법

`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 수정 안내

- 카페 이름, 메뉴, 가격, 주소, 전화번호는 `index.html`의 예시 값입니다. 실제 정보로 바꿔서 사용하세요.
- 색상은 `style.css`에서 바꿀 수 있습니다.
